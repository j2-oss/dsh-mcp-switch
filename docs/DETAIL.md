# MCP 工具开关

在 DSH 设置里增加一个「MCP 工具开关」页面，并在对话里提供 `mcp_switch` 工具。同一个开关，两处都能操作。

## 开关做了什么

每个 MCP 服务默认关闭：只有打开的服务才会把工具定义发给模型，平时的请求只带必要的那部分。关闭的服务不消耗 token；服务连接保留，打开立即恢复，不需要重连、重启或改配置。

## 在哪里操作

1. 设置 → 侧栏「MCP 工具开关」：每个服务一行，右侧是开关，行内显示工具数量与当前状态；上方有「全部开启」「全部关闭」。
2. 对话：说「把 github 关掉」「打开 io-draw」「现在哪些 MCP 在吃 token」，由 `mcp_switch` 工具执行。

## 动作

| action | 参数 | 结果 |
|---|---|---|
| `list` | — | 每个 MCP 服务的工具数与开关状态 |
| `disable` | `server` | 从下一步起隐藏该服务的工具 |
| `enable` | `server` | 恢复该服务的工具 |

服务键就是工具名中间那一段：`mcp__github__create_issue` 属于 `github`。

## 限制

- 开关控制工具**可见性**，不会卸载 MCP 服务或断开连接。
- 完全没连接的服务（没有注册任何工具）不会出现在列表里。
- 状态存在 `<harness home>/mcp-switch.json` 的 `enabled` 列表里，创建每个 agent 时重新应用，因此重启后保留。
- 仅覆盖以全局方式注册的 MCP 工具（`dsh-mcp-client` 注册的即为全局）；agent 作用域内注册的工具不受影响。
